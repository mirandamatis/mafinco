# Mafinco Home Page

Home page autonome pour Mafinco, inspiree de la maquette fournie.

## Lancer

Ouvrir `index.html` dans un navigateur.

Pour lancer un petit serveur local depuis ce dossier :

```bash
python3 -m http.server 5174
```

Puis ouvrir `http://localhost:5174`.

## Structure

- `index.html` : structure de la home page
- `src/styles.css` : styles de la hero et des mockups
- `src/app.js` : interaction legere au mouvement de souris
