## Notes UX

| Élément | Justification |
|---|---|
| **Chiffres de traction first** | Un partenaire bancaire décide en fonction des données — données avant tout |
| **3 modèles de partenariat** | Adapte l'offre à différents types de partenaires (néobanque vs courtier) |
| **Formulaire sur la page** | Pas de redirect — réduit la friction pour les prospects B2B |
| **Champ "Société" obligatoire** | Différencie les demandes sérieuses B2B des contacts grand public |
