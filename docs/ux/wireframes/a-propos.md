## Notes UX

| Élément | Justification |
|---|---|
| **Section Engagements** | Critique pour la confiance — app financière, les utilisateurs ont besoin d'être rassurés |
| **Timeline** | Montre que l'app est sérieuse et en croissance, pas un projet amateur |
| **Photos équipe** | Humanise la marque, crée la confiance (marché financier = confiance = visages) |
| **CTA download en fin de page** | Après avoir convaincu sur les valeurs → capturer l'action |
