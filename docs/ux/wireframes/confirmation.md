## Variantes selon l'origine du formulaire

| Source | Message |
|---|---|
| **Contact général** | "Votre message a bien été envoyé ! Nous vous répondrons sous 72h ouvrables." |
| **Formulaire partenaire** | "Votre demande de partenariat a été reçue. Notre équipe vous contactera sous 48h ouvrables." |

## Notes UX

| Élément | Justification |
|---|---|
| **Icône succès** | Feedback visuel immédiat, rassure que le message est parti |
| **CTA download** | Transforme une page de sortie en opportunité de conversion |
| **Message personnalisé selon source** | Réponse adaptée au contexte (partenaire vs utilisateur) |
