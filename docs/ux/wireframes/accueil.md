## États spéciaux

| État | Comportement |
|---|---|
| **Loading** | Skeleton screen sur le hero (texte grisé animé), images en blur-up |
| **Sans JS** | Toutes les sections visibles statiquement, animations désactivées |
| **Prefers-reduced-motion** | Toutes les animations désactivées (CSS media query) |
