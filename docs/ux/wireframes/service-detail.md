## Notes UX

| Élément | Justification |
|---|---|
| **Prix affichés dès la liste** | Répond au besoin n°1 : transparence (friction identifiée) |
| **Badges "Nouveau" / "Populaire"** | Aide à la décision, crée un sentiment d'urgence douce |
| **Encadré contre-indications** | Responsabilité, confiance, évite les appels inutiles |
| **Cta double "RDV" + "Contact"** | Laisse le choix entre action immédiate ou question préalable |
| **Témoignages par catégorie** | Plus pertinent qu'un témoignage général sur cette page |
