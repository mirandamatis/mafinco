## Notes UX

| Élément | Justification |
|---|---|
| **Blocs alternés gauche/droite** | Crée un rythme visuel, évite la monotonie — pattern standard landing SaaS |
| **Mockup d'écran réel** | Montre concrètement l'app — réduit le risque perçu au téléchargement |
| **Logos partenaires** | Crédibilité + signal que l'app est "vraiment" connectée aux banques |
| **Points bullet courts** | Scannable rapidement — les visiteurs ne lisent pas, ils scannent |
