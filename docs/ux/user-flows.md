## Parcours 1 : Découverte organique & téléchargement (Léa & Thomas)

**Objectif :** Découvrir Mafinco via Google, comprendre la valeur, télécharger l'app.
**Canal d'entrée :** SEO — recherche "application budget couple" ou "partage dépenses couple"

```
[1. Recherche Google]
       │
       ▼
[2. Page Accueil (/)]
   │   • Hero : stat "70% des couples" → accroche immédiate
   │   • Scanne "Comment ça marche" (3 étapes)
   │   • Lit la section "Pour quel couple ?" — clique "Couple avec revenus différents"
   │
   ▼
[3. Scroll vers fonctionnalités (section sur l'accueil)]
   │   • Voit "Calcul proportionnel aux revenus"
   │   • Convaincu — cherche le CTA
   │
   ├── [Convaincu] ──► [4a. Clic sur "Télécharger sur App Store" ou "Google Play"]
   │                       • Redirection vers la fiche app
   │                       • Téléchargement
   │                       ► FIN — Converti
   │
   └── [Veut en savoir plus] ──► [4b. Page /fonctionnalites]
                                      • Lit les 4 blocs de fonctionnalités
                                      • Voit les mockups de l'app
                                      • CTA final → Téléchargement
```

### Temps estimé : 1 min 30 s – 3 min
### Points de friction :
- ❌ Si la valeur n'est pas claire en < 5s → bounce immédiat
- ❌ Si les CTA App Store/Android ne sont pas visibles au premier scroll → abandon
- ✅ **Solution :** Hero avec accroche chiffrée + CTA double above the fold + mockup de l'app visible

## Parcours 2 : Publicité réseaux sociaux & validation sociale (Maxime & Camille)

**Objectif :** Arriver via une pub Instagram, se rassurer via les avis, télécharger.
**Canal d'entrée :** Publicité Instagram/TikTok → landing page accueil ou /avis

```
[1. Pub Instagram "Préparez votre projet immo à deux"]
       │
       ▼
[2. Page Accueil (/)]
   │   • Hero orienté immobilier (si pub ciblée) ou générique
   │   • Voit la note globale (4.8★) dans la section témoignages
   │   • Sceptique → veut voir plus d'avis
   │
   ▼
[3. Page /avis]
   │   • Note globale en évidence (App Store + Google Play)
   │   • Filtre "Projet immobilier"
   │   • Lit 3 témoignages de couples acheteurs
   │   • Voit "Mis en relation avec Pretto en 48h"
   │
   ▼
[4. Page /fonctionnalites]
   │   • Bloc "Conseils d'investissement IA"
   │   • Bloc "Simulation crédit" (ou partenariat courtier)
   │
   ▼
[5. CTA Téléchargement]
   │   • Bouton App Store ou Google Play
   │
   ► FIN — Converti
```

### Temps estimé : 3 – 5 min
### Points de friction :
- ❌ Avis génériques non filtrés → ne se reconnaît pas dans les témoignages
- ❌ Pas de mention immobilier dans l'app → perd confiance
- ✅ **Solution :** Filtres personas sur /avis + témoignages segmentés + cas d'usage immobilier visible

## Parcours 3 : Contact partenaire B2B (Directeur partenariats, Boursorama)

**Objectif :** Évaluer Mafinco comme partenaire d'affiliation, remplir le formulaire partenaire.
**Canal d'entrée :** LinkedIn, email cold outreach, ou bouche-à-oreille B2B

```
[1. Email / LinkedIn → lien vers mafinco.fr/partenaires]
       │
       ▼
[2. Page /partenaires]
   │   • Hero : "Touchez 14 millions de couples français"
   │   • Chiffres de traction (utilisateurs actifs, taux d'engagement)
   │   • Modèles de partenariat : affiliation, co-branding, API
   │
   ▼
[3. Scroll vers bas]
   │   • Logos de partenaires existants → validation par pairs
   │   • Formule commissions claires
   │
   ├── [Prêt à contacter] ──► [4a. Formulaire partenaire]
   │                               • Nom, prénom, entreprise
   │                               • Email professionnel
   │                               • Type de partenariat
   │                               • Message court
   │                               • Envoi
   │                               ► Page /confirmation
   │
   └── [Veut en savoir plus] ──► [4b. Page /a-propos]
                                      • Équipe fondatrice
                                      • Mission + engagements RGPD
                                      • Retour sur /partenaires → Formulaire
```

### Temps estimé : 5 – 10 min
### Points de friction :
- ❌ Chiffres de traction absents ou vagues → pas crédible pour un partenaire bancaire
- ❌ Formulaire avec champ "société" manquant → friction
- ✅ **Solution :** Chiffres de traction en avant, formulaire B2B dédié avec champs entreprise

## Parcours 4 : Recherche directe "Mafinco" (utilisateur référé)

**Objectif :** Un ami a recommandé l'app — l'utilisateur cherche directement le nom.
**Canal d'entrée :** Recherche Google "Mafinco app" ou lien direct

```
[1. Recherche Google "Mafinco" → résultat #1 → mafinco.fr]
       │
       ▼
[2. Page Accueil]
   │   • Confirmation immédiate : logo + tagline claire
   │   • Pas besoin de convaincre → veut juste trouver le lien de téléchargement
   │
   ▼
[3. CTA Téléchargement (above the fold)]
   │   • Clic direct App Store ou Google Play
   │
   ► FIN — Converti en < 20 secondes
```

### Temps estimé : < 30 s
### Point clé : Le CTA doit être immédiatement visible — aucun scroll requis pour trouver le lien de téléchargement.

## Parcours d'erreur : Page 404

```
[Lien mort / URL incorrecte]
       │
       ▼
[Page 404]
   │   • Illustration couple perdu (ton humoristique et bienveillant)
   │   • Message : "Oups, cette page ne partage pas les dépenses correctement..."
   │
   ├── CTA 1 : [Retour à l'accueil]
   │
   ├── CTA 2 : [Voir les fonctionnalités]
   │
   └── Raccourcis : [Télécharger l'app] [Partenaires] [Contact]
```

## Récapitulatif des points de friction transverses

| Friction | Impact | Solution UX |
|---|---|---|
| Valeur non comprise en < 5s | Bounce (tous) | Accroche + stat chiffrée + mockup dans le hero |
| CTA download non visible | Abandon (Léa & Thomas, Maxime & Camille) | Sticky header mobile + CTA above the fold |
| Avis non segmentés | Pas de reconnaissance (Maxime & Camille) | Filtres par profil de couple sur /avis |
| Page partenaires trop vague | Perte de confiance B2B | Chiffres de traction + logos partenaires + formulaire dédié |
| iOS-only visible | Abandon Android | Toujours afficher les 2 boutons simultanément |
| RGPD peu visible | Frein à l'inscription | Mention RGPD dans le footer + page dédiée accessible |
