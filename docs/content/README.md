- **Ton :** Direct, bienveillant, moderne — sans jargon financier sauf pages légales

- **Chiffres clés cohérents :** 50 000 utilisateurs · 4,8/5 · 2 400 avis · 14M couples cibles

- **CTA :** Toujours "Télécharger sur App Store" + "Télécharger sur Google Play" en doublon
