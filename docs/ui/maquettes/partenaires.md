## Notes visuelles

| Décision | Justification |
|----------|---------------|
| **Hero Navy** | Signal immédiat "page professionnelle" — rupture avec les pages grand public |
| **CTA vert sur hero Navy** | Seul CTA vert sur fond sombre — contraste élevé, attire l'œil |
| **Stats en cards bleues claires** | Les décideurs bancaires lisent d'abord les chiffres — les mettre en avant |
| **Formulaire max-width 600px** | Evite un formulaire trop large sur grand écran — lecture plus confortable |
