## Notes visuelles

| Décision | Justification |
|----------|---------------|
| **Fond alternés #FFFFFF / #F4F6FE** | Rythme visuel sans rupture brutale, maintient la lecture |
| **Mockups avec fond de couleur douce** | Ne pas flotter un mockup sur pur blanc — ajouter un fond décoratif #E8EDFB léger |
| **Icônes check verts** | Les bullet points deviennent des preuves de fonctionnalité — le vert = validé |
| **Logos partenaires grisés** | Évite la cacophonie visuelle de multiples couleurs de marque |
