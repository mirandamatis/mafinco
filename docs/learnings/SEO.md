# Leçons SEO

_Ce fichier est mis à jour automatiquement par @retro-agent après chaque projet._

## Initialisation
- Vérifier que le sitemap est soumis à Google Search Console
- Ne pas oublier les balises hreflang si le site est multilingue
- Tester avec Lighthouse et PageSpeed Insights avant livraison

## 2026-06-05 — Projet Elodie Esthétique
- Le formulaire sans backend peut être signalé — prévoir un service externe (Formspree, EmailJS, Resend) dans l'audit
- Vérifier que les pages "Mentions légales" et "Confidentialité" existent (obligation légale, lien souvent présent dans le footer)
- Si des photos placeholder sont utilisées, documenter clairement leur remplacement par des visuels réels dans le plan d'action
